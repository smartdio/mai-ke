设计版本规划

A 头像版（圆形头像） 800 x 800px
元素
  • 直接使用 brand/logos/avatars/mai-avatar-logo-color-circle.png 作为基础
  • 周围留白 ≥ 12%（按 VI 规范）
  • 不添加额外装饰

用途：所有平台头像（直接使用现成资产）

B 竖版主理人海报 1080 x 1920px · 9:16
布局（自上而下）
  • 顶部 30%：白色背景 + 品牌色 eyebrow
  • 中部 40%：完整双语锁定组合（居中）
  • 底部 30%：
    • 一句话定位：「MAI = Maker + AI = 无限创作」
    • 二维码占位
    • 公众号/简介信息
    • 底部三色短线（红/黄/黑）
色彩策略
  • 浅色背景为主，遵循"使用面积克制"
  • 仅 CTA 按钮使用 Mai Orange
  • eyebrow 文字用 Action Red：「AI 内容创作者 · 一人公司 + AI Agent 团队」

适用平台：小红书 / 抖音 / 视频号

C 横版主理人海报 1920 x 1080px · 16:9
布局
  • 左侧 30%：圆形头像 + 速度线装饰背景
  • 右侧 70%：eyebrow + 中文大标题（错位色影）+ 英文小标题 + 三句话定位（人的创意 × AI 的能力 / 一人公司 + AI Agent 团队 / 为客户包装媒体运营形象）+ 二维码占位 + 底部三色短线
色彩策略
  • 使用 Night Blue 深色背景
  • 文字用白色 + 黄色强调
  • 二维码用白色背板

适用平台：公众号 / B站 头图

D 方版个人名片 1080 x 1080px · 1:1
布局（4 区块）
  • 顶部：圆形头像（居中）
  • 中上：品牌字「麥客不停」（错位色影）
  • 中下：
    • 角色身份：AI 内容创作者 · 一人公司 + AI Agent 团队
    • 一句话：「MAI = Maker + AI = 无限创作」
    • 二维码
  • 底部：三色短线 + 公众号/小红书/微博标识
色彩策略
  • 浅暖色背景（cream 渐变）
  • 头条用 Action Red
  • 装饰用 Burst Yellow

适用平台：朋友圈 / 微信群

RULES

视觉规范遵循清单

  • 头像标独立使用场景：仅用于头像 / 角标 / 水印
  • 字标字体：DouyinSans Bold + Inter Black/ExtraBold
  • 主组合优先使用中英文彩色版
  • 周围留白 ≥ 12%
  • 不改变主色 / 不拉伸字标 / 不拆散速度线
  • 不使用渐变 / 发光 / 投影 / 额外速度线
  • 文字效果仅在字标使用（错位色影），正文不使用

  • 横版海报是否使用深色背景？
  • 方版名片标题字号是否需要调整？
