## 视觉规范依据

**来源**：`brand/guidelines/visual-identity.html`（已复制到项目 brand/ 目录作为本项目标准）

### 核心识别特征（必须保留）

- **人物**：米色鸭舌帽 + 黑框眼镜 + 短胡须 + 橙色上衣
- **背景**：红黄放射速度线（漫画冲击感）
- **字标**：错位色影（红阴影 + 黄填充 + 黑色描边）
- **底部三色短线**：红 / 黄 / 黑

### 配色系统

| 颜色 | 色号 | 用途 |
|------|------|------|
| Ink Black | `#101010` | 主标题、轮廓、字标描边 |
| Action Red | `#E60012` | 强调色、CTA、eyebrow 文字 |
| Burst Yellow | `#FFCF00` | 字标阴影、装饰背景 |
| Mai Orange | `#FF6A00` | 主按钮、推荐标识 |
| Night Blue | `#101D33` | 深色底品牌环境 |

### 字体系统

| 元素 | 字体 | 来源 |
|------|------|------|
| 中文字标 | DouyinSans Bold（抖音美好体） | `brand/fonts/DouyinSansBold.ttf` |
| 英文字标 | Inter Black / ExtraBold | `brand/fonts/Inter-Black.otf` + `Inter-ExtraBold.otf` |
| 正文 | 系统字体回退到 Noto Sans CJK SC | — |

## 设计版本规划（基于新规范）

### 版本 A：头像版（圆形头像）

**规格**：800x800px（圆形裁切）
**元素**：
- 直接使用 `brand/logos/avatars/mai-avatar-logo-color-circle.png` 作为基础
- 周围留白 ≥ 12%（按 VI 规范）
- 不添加额外装饰

**用途**：所有平台头像（直接使用现成资产）

### 版本 B：竖版主理人海报（9:16）

**规格**：1080x1920px（小红书 / 抖音 / 视频号）

**布局**（自上而下）：
1. **顶部 30%**：白色背景 + 品牌色 eyebrow
2. **中部 40%**：完整双语锁定组合 `brand/logos/lockups/mai-lockup-bilingual-color.png`（居中）
3. **底部 30%**：
   - 一句话定位：「MAI = Maker + AI = 无限创作」
   - 二维码占位
   - 公众号/简介信息
   - 底部三色短线（红/黄/黑）

**色彩策略**：
- 浅色背景为主，遵循"使用面积克制"
- 仅 CTA 按钮使用 Mai Orange
- eyebrow 文字用 Action Red 例：「AI 内容创作者 · 一人公司 + AI Agent 团队」

### 版本 C：横版主理人海报（16:9）

**规格**：1920x1080px（公众号 / B站 头图）

**布局**：
1. **左侧 30%**：圆形头像 + 速度线装饰背景
2. **右侧 70%**：
   - eyebrow + 中文大标题（错位色影效果）
   - 英文小标题（MAI UNSTOPPABLE）
   - 三句话定位（人的创意 × AI 的能力 / 一人公司 + AI Agent 团队 / 为客户包装媒体运营形象）
   - 二维码占位
   - 底部三色短线

**色彩策略**：
- 使用 Night Blue 深色背景
- 文字用白色 + 黄色强调
- 二维码用白色背板

### 版本 D：方版个人名片（1:1）

**规格**：1080x1080px（朋友圈 / 微信群）

**布局**（4 区块）：
1. **顶部**：圆形头像（居中）
2. **中上**：品牌字「麥客不停」（错位色影）
3. **中下**：
   - 角色身份：AI 内容创作者 · 一人公司 + AI Agent 团队
   - 一句话：「MAI = Maker + AI = 无限创作」
   - 二维码
4. **底部**：三色短线 + 公众号/小红书/微博小图标

**色彩策略**：
- 浅暖色背景（cream 渐变）
- 头条用 Action Red
- 装饰用 Burst Yellow

## 视觉规范遵循清单

· 头像标独立使用场景：仅用于头像 / 角标 / 水印
· 字标字体：DouyinSans Bold + Inter Black/ExtraBold
· 主组合优先使用中英文彩色版
· 周围留白 ≥ 12%
· 不改变主色 / 不拉伸字标 / 不拆散速度线
· 不使用渐变 / 发光 / 投影 / 额外速度线
· 文字效果仅在字标使用（错位色影），正文不使用
