# MAI Unstoppable 长文站：视觉与排版设计

> 文档状态：风格基线 v1.1  
> 更新日期：2026-09-03  
> 关联文档：[整体方案](./PROJECT-PLAN.md) · [技术设计](./TECHNICAL-DESIGN.md)

## 1. 定位

网站采用“当代独立出版物”方向：阅读体验安静、克制，插画鲜活、有温度。页面本身不复刻漫画分镜，也不使用旧版放射纹章、复古海报或强烈撞色；漫画感主要来自官方 Logo、人物线稿和局部图像叙事。

核心印象：

- 温暖但不泛黄
- 明亮但不刺眼
- 有色彩但不杂乱
- 有出版物秩序，但不显得学院化
- 能容纳中文长文，也能自然切换到英文长文

生成提示与参考关系：[`visual-reference/mai-unstoppable-visual-style-standard-v2.prompt.md`](./visual-reference/mai-unstoppable-visual-style-standard-v2.prompt.md)

- 尺寸：1750 × 899 px

- 用途：判断后续插画、封面、页面配色和综合色温是否属于同一视觉系统
- 它是风格标准，不要求所有页面复用同一场景，也不要求所有头图都把 Logo 画进图片

v2 同时承担角色一致性基准：

- 麥客必须保留鸭舌帽、矩形眼镜、短胡须、成熟漫画化脸部、橙色内搭和蓝灰外套等识别特征。
- Agent 的形象以 `content/series/unstoppable-office/bible/characters/公共参考/hermes-ai-team-poster-v2-new-style.png` 及各角色目录为权威来源。
- 不得使用没有进入角色 Bible 的通用人类形象或同质化圆头机器人代替正式角色。

v1 因人物与漫画设定不一致而停止使用，已移至 `visual-reference/archive/`，不得作为生成参考或页面图片继续引用。

定标图确立的规则：

1. 底色以明亮暖白为主，不使用做旧纸张滤镜。
2. 黄色用于光线、纸张和木质感，应清澈、轻盈，不形成土黄蒙层。
3. 蓝色承担画面结构和冷暖平衡，纯度高于传统低饱和水彩。
4. 可使用少量清新的植物绿和自然木色，但页面 UI 不扩展为多色系统。
5. 线稿明确，填色保留透明水彩感；整体介于赛璐璐和平涂水彩之间。
6. 官方 Logo 是独立品牌资产，永远使用原始色值，不随插画或页面主题调色。

## 3. 色彩系统

### 3.1 页面核心色

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 明亮暖白 | `#FFFDF7` | 全站主背景 |
| 纸面白 | `#FFFFFF` | 图片底、引用区、局部浮层 |
| 蓝黑墨色 | `#1C2A35` | 主标题、正文 |
| 次级墨色 | `#52606A` | 摘要、说明、元数据 |
| 出版蓝 | `#2F638C` | 链接、栏目识别、重点编号 |
| 清浅蓝 | `#DDECF2` | 淡色背景、信息区 |
| 日光黄 | `#EBC35A` | 小面积标记、细线、选中状态 |
| 纸面边线 | `#DAD8CF` | 分隔线、表格和图片边界 |

页面核心色只使用暖白、墨色、蓝和黄。红色、橙色不作为常规按钮、标签、标题或装饰色使用。

### 3.2 Logo 例外

Logo 使用官方原文件，保留其中的黑、红、黄、橙色。页面色彩系统不得覆盖 Logo，也不以 CSS 滤镜、透明度或混合模式改变 Logo。

推荐浅色背景版本：

`brand/logos/lockups/mai-lockup-bilingual-color.png`

### 3.3 插画扩展色

插画可在核心色之外使用叶绿色、肤色和自然木色。扩展色只存在于图像内部，不进入站点导航、按钮、分类或状态系统。

## 4. 字体系统

沿用已经确认的出版物字体方向。

| 内容 | 中文 | 英文/西文 | 建议字重 |
| --- | --- | --- | --- |
| 文章标题、栏目标题 | Noto Serif SC | Source Serif 4 | 600–700 |
| 正文、摘要、引文 | Noto Serif SC | Source Serif 4 | 400–500 |
| 导航、按钮、图注 | Noto Sans SC | Inter | 500–700 |
| 期号、日期、代码式元数据 | Noto Sans SC | Inter | 400–700 |

规则：

- 正文必须以衬线字体为主，形成长文出版物气质。
- Logo 中的字体属于 Logo 图形，不据此把页面标题改成抖音美好体。
- 中文与英文可以在同一页面自然混排；英文正文不使用中文字体回退。
- 正式上线时字体文件自托管，海外站和国内站各自完整部署，不依赖 Google Fonts。
- `font-display: swap`，并提供系统字体回退，避免字体失败时正文不可读。

## 5. 排版比例

### 5.1 桌面端

- 页面最大宽度：1280 px
- 左右安全边距：32–48 px
- 首页：12 栏网格，重点内容可占 7–8 栏，说明占 4–5 栏
- 文章正文：680–740 px
- 中文正文：19–20 px，行高 1.9–2.0
- 英文正文：19–20 px，行高 1.7–1.8
- 中文每行约 32–40 个汉字
- 英文每行约 65–75 个字符
- 文章 H1：桌面端 56–76 px，移动端 38–48 px
- H2：32–40 px；H3：23–28 px

### 5.2 移动端

- 页面边距：20 px
- 单栏连续阅读，章节之间依靠标题与留白形成节奏
- 元数据允许换行，不缩小到难以阅读
- 正文图片可贴近内容边缘，但不产生横向滚动
- 表格优先重排；确实无法重排时才允许局部横向滚动

## 6. 首页版面

首页不是营销落地页，而是出版物首页。

首页使用统一宽网格组织三段编辑节奏：

1. 站头与 Hero 共用同一淡彩画面：品牌、导航、期号、主标题、导语、入口和格式信息组成完整封面。
2. 最新文章：Hero 后直接进入纸面式纯文字目录；一条重点文章展开显示摘要，其余文章收起显示，依靠留白、编号和细线组织，不使用整块彩色背景。
3. 系列与项目：使用不对称编辑拼版，淡彩画面与文字块共享基线，不依赖额外人物插画。

页脚继续保持轻量，首页与文章页共用同一结构：品牌说明、站内导航、已核实的媒体账号，以及作品与项目入口。账号使用文字链接，不堆叠彩色平台图标；没有稳定公开主页的账号只显示可检索名称，不使用假链接或平台通用首页占位。海外/国内站切换待双站域名确定后再加入。

首页首屏只允许一个真正的视觉焦点。不得同时出现大标题、彩色 Logo、多个彩色按钮和多张抢眼图片。

首页的创意感来自比例、非对称构图、编号、留白和色彩节奏，而不是卡片、插画或装饰线的数量。不同背景必须服从同一网格与对齐基线；淡彩承担章节转换，纯色承担内容状态，细线只用于确有必要的信息分组。

Hero 默认使用无人物、无文字、无 Logo 的蓝白淡彩或水彩背景。人物场景插画只在内容确实需要叙事时出现，不作为每期首页的固定负担。正文目录及系列推荐可以使用单一纯色或非常浅的淡彩底色，但同一屏不并列使用多种强调色。

首页的核心视觉资产是文字排版本身。主标题、文章标题和系列标题使用衬线字体建立印刷物骨架；导航、栏目、日期、编号和格式信息使用无衬线字体形成索引系统。全页仍只允许三档字号，层级主要通过字重、行距、栏宽、人工控制的断行、对齐与留白建立。水彩和纯色必须退居文字之后，只承担纸面层次与章节节奏。

首页与所有内页共用同一套站头组件：官方原色 Logo、品牌文字、导航、语言入口、高度和间距不得分叉。首页站头叠放在 Hero 淡彩上；内页站头直接使用同一幅淡彩资产和相同纸白遮罩，正文从站头下方正常开始。

## 7. 文章页版面

文章页优先满足连续阅读。

- 页头先显示栏目、标题、摘要、作者、日期和预计阅读时间。
- 头图是正文的一部分，不作为难以阅读文字的背景。
- 首页主视觉也必须收在页面版心内；先确定版面尺寸，再让图片在容器中裁切适配，图片本身不得撑大首屏或溢出容器。
- 桌面端与移动端都使用单一正文阅读轴，不设置侧栏大纲或悬浮目录。
- 无论文章长短都不显示内容大纲；长文依靠语义化章节标题和稳定锚点组织。
- 旁注仅用于补充来源、术语或过程信息，不能放置关键结论。
- H2 前留出明显章节间距，使用短黄线或蓝色编号帮助定位。
- 引文以字号、留白和细线表达，不使用厚重色块。
- 图注使用无衬线字体，与正文保持清楚区分。
- 文章末尾提供修订记录、来源、许可、上一篇/下一篇和系列关系。

## 8. 图片与插画

- 主视觉优先使用 16:9、约 1.9:1 或适合文章内容的横幅比例。
- 插画背景保持明亮；暗部主要使用蓝黑或蓝灰，不用浑浊棕黑。
- 线条可以明确，但不增加粗重漫画速度线、爆炸框或放射纹。
- 水彩纹理用于丰富表面，不得降低文字和主体辨识度。
- 图片不强制圆角；出版物主图默认直角或 2 px 微圆角。
- 文章头图与正文插图统一限定在正文版心内，不做向两侧出血式外扩；图片、图注与正文使用相同的左右边线。
- 不在生成图片里绘制正文标题、日期等可由 HTML 表达的文字。
- Logo 如需出现，优先在 HTML 中叠放官方原文件，而不是让生成模型重画。

## 9. 组件语言

- 导航和链接：文本为主，细下划线或颜色变化反馈。
- 按钮：只用于真实操作；小圆角、实色或细边框，不使用胶囊标签堆叠。
- 卡片：尽量取消盒子感，用网格、留白和 1 px 分隔线组织内容。
- 分类：使用文字栏目名，不为每个分类分配颜色。
- 圆角：0–4 px 为主；不采用大面积 16–24 px 圆角卡片。
- 阴影：常规内容不使用；仅在必要浮层中使用非常轻的阴影。
- 动效：150–240 ms，服务于链接和图片查看；不做视差滚动或大幅入场动画。

## 10. 可访问性与输出

- 正文与背景对比度至少达到 WCAG AA。
- 焦点状态必须清晰，不以颜色作为唯一提示。
- 支持 `prefers-reduced-motion`。
- 图片带准确的 `alt`、宽高和图注。
- 打印样式移除导航，保留标题、作者、日期、正文、图注和 URL。
- 页面不强制深色模式；出版物视觉以固定暖白纸面为主，系统深色模式不能自动反转品牌图片。
