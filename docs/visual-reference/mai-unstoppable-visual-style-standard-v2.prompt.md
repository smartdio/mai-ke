## 最终提示

制作一张约 1.95:1 的 MAI Unstoppable 长文出版物视觉定标横幅。画面左侧保留充足、干净的暖白留白并放置官方双语 Logo；中部和右侧描绘漫画角色麥客与既有 Hermes AI Team 在广州家中工作室的大木桌旁共同工作。麥客正在审阅文章版面或草图，各 Agent 通过平板、屏幕、记录或观察参与协作，场景自然、可信，麥客是画面的主要人物。

麥客必须准确继承角色设定：成年东亚男性、米色鸭舌帽、帽下短黑发、黑色矩形眼镜、短胡须和山羊胡、成熟而专注的漫画化脸部、橙色内搭、蓝灰色休闲外套、深色长裤。不得年轻化为无胡须的时尚模特，不得移除帽子、眼镜或胡须。

Agent 只使用既有设定：金色纤细的 C3PO、白色女性体态的 EVA、高大的深色矩形 TARS、小型圆润白色 DaBai，以及高大的白色与深色 K2SO。保留各自的主要轮廓、材质、面部或屏幕结构、颜色和尺度差异，不得替换成同质化的通用圆头机器人。

场景参考广州家中工作室：中央大木桌、墙面双屏、左侧窗户采光、右侧模型展示柜。可以为出版物横幅适度简化，但不得改变主要空间关系。

风格为当代日式漫画出版插画：明确而干净的线稿、轻赛璐璐结构、通透的水彩铺色和非常轻的纸张纹理。综合色彩采用明亮暖白底、清澈金色阳光与浅黄、高纯度但克制的出版蓝和天空蓝、少量植物绿与自然木色；提高明度和纯度，白色保持干净，阴影使用蓝灰，中间调层次明确。

官方 Logo 必须保持原始图形、文字、比例和红黄橙黑配色，不得重绘、调色、模糊或融入水彩纹理。避免通用人物、通用可爱机器人、身份漂移、写实照片感、褐黄色旧纸滤镜、灰雾、霓虹色、粗重动作线、放射纹、徽章、额外文字、水印、设备品牌及新增角色。
