我最初想做的，并不是一座准确的数字校园。我想知道：一段已经模糊的个人记忆，能不能在人的判断与 Agent 的执行之间，重新获得可以行走的形状。

问题从一张很粗糙的草图开始。教学楼、操场、宿舍和校门只有大致位置，比例并不可信。真正困难的地方，不是把这些方块放进浏览器，而是判断哪些错误来自工具，哪些错误来自我自己的记忆。

事情从哪里开始

我把资料拆成三类：可以验证的事实、只能依靠记忆的空间关系，以及为了让体验成立而必须做出的设计决定。这种区分很重要，因为 Agent 很擅长把模糊的要求迅速变成具体结果，却不会自动知道哪一部分应该忠于事实。

速度不是这次协作里最重要的东西。最重要的是，我们能否一直知道自己正在相信什么。

于是，每一次生成都不再只是“做得像不像”，而是一轮带着证据的判断。浏览器中的灰盒模型、旧照片、手绘方向和实际步行尺度，被放在同一个讨论里。

记忆不是地图

记忆会保留情绪强烈的节点，却会压缩那些每天经过的距离。校门可能显得很高，操场可能离教学楼很远，但真实比例往往并不是这样。与其隐藏这种偏差，我更愿意把它看作项目的一部分。

Working method

把不确定性也写进工作流

事实、回忆与设计判断分别记录。Agent 可以帮助推进和交叉检查，但不能把三者混成一个看似确定的答案。

把工作交给 Agent

我开始把工作拆成可以独立检查的小任务：整理资料、建立比例、制作原型、寻找冲突、记录决定。Agent 可以各自推进，但关键判断仍需要回到同一个上下文。协作的价值，不是把人从项目里移走，而是让人的注意力留在真正需要判断的地方。

最后留下什么

最终留下的不只是一座可以打开的三维校园，还有一套更清楚的工作方法：先声明不确定性，再让不同能力并行工作，最后用可以被追溯的证据重新汇合。
